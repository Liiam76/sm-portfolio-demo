# Project notes: sm-portfolio-demo

- Sample portfolio for a fictional Lagos social media manager. All content is invented and labeled as a sample. Never present it as real.
- Content lives in `content/` (persona, cases). Metrics are derived from raw from/to values in `lib/metrics.ts`. Do not hardcode percentages.
- `npm test` runs content tests, including a house-style lint: no em dashes, en dashes, semicolons, curly quotes or banned vocabulary in copy.
- Branch flow: feature branch, PR into `staging`, PR from `staging` into `main`. Never push to `main` directly.
- `lib/env.ts` `isLive` is true only when `VERCEL_GIT_COMMIT_REF === "main"`. `/variants` 404s and robots block indexing everywhere else.
- Chosen design direction: Feed (see `components/variants/Feed.tsx` and `app/(site)/`). Other variants stay on staging for comparison.
- UI changes need screenshots at 320, 375, 390, 428, 768, 1024 and 1440 px (plain viewport, not `isMobile`) plus an axe-core pass.
- The CV PDF in `public/` is generated by printing `/cv` to A4 with headless Chrome. Regenerate it after content changes.
